# Contracts

Foundry 기반 스마트 컨트랙트 영역이야.

계획서의 Phase 5에서 다음 기능을 구현해.

- Certificate 발급
- Certificate 조회
- Certificate 폐기
- Certificate Hash, Issuer, Subject 기록
- 발급·폐기 Event

초기 네트워크는 Base Sepolia고, 서버는 Wallet Private Key를 보관하지 않아.

## 명령어

```powershell
forge build
forge test
```

현재는 모노레포 경계와 Foundry 설정만 준비되어 있고, 실제 컨트랙트 구현은 Phase 5에서 추가해.
